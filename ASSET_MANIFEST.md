## Scope and use rule

This manifest accompanies the files in `assets/images/`. Twenty-six rows have a local file and represent the downloaded archival library. Two rows are marked **source-only** because the Library of Congress image host returned HTTP 403 from this environment; their source records and stated reuse conditions are retained for later retrieval. Each reference was selected because its **individual source record** states a reuse condition. Local files are faithful copies of the linked source files. The descriptions are production metadata, not evidence that the local copy has any broader licence than stated by the source.

> **Rights control:** Do not treat newspaper images as cleared merely because a newspaper article is publicly accessible. Do not use a file beyond its listed licence or rights statement. Preserve creator, repository, source-page, licence, and attribution data in your content-management system. Seek legal review before commercial, global, or derivative distribution, especially for public-domain claims tied to a particular jurisdiction.

## Deliberate exclusions and source-only references

The **Indian Independence Act 1947** PDF is retained in the Partition research note as a primary document rather than a still image. The **India–Pakistan Refugees** OGV is a 1971 U.S. National Archives film that requires editorial content review before extracting a still. The Lincoln Memorial crowd and Triangle pier-morgue crowd are source-only above because their direct Library of Congress image paths returned HTTP 403 from this environment. Those choices leave **26 actual downloaded images**, within the requested 20–30 range, rather than silently substituting lower-resolution search thumbnails or converting trauma-adjacent material into a decontextualised image.

## Quality-control checklist

Before an asset reaches a published world, verify the source link still resolves, the licence statement still appears as recorded, creator and repository are stored with the asset, a meaningful caption names the date/place without overclaiming, the event time-state matches the asset, a content note appears where indicated, and any derivative respects CC BY-SA terms. Never remove a visible provenance note solely for visual polish.
